**each/every/either/neither/any/none**


each can be used as both adj and pronoun.and each is used for 2 or >2
example:

each student was there.(here each is used as adj for the noun student)
each of the students was there(here each is used as pronoun && when the preposition of is used then the noun should be plural-students)

every is used only as adjective and used only for >2

example:
every student was there

each of these(each/every/either/neither/any/none) uses the singular verb.
examples:
Each girl was present.(here the verb corresponds to subject girl so singuler verb is used)
Each of the girls was present.(here the verb corresponds to the pronoun each so singular verb is used)
Every girl was present.
❌ Every of the girls was present.
Each student wishes to complete his/her work on time.
Each of the students wishes to complete his/her work on time.
Every class is ready to attend the seminar.

every focuses making a claim about the whole set as a general totality. "Each" focuses on items one-by-one individually.
example:
Practically every part of the banana tree is used by man.(here every is used to resprent the whole part as one ,each will be used when need to specify individually)
every citizen has the right to vote. (general statement about the whole group)
each of the five candidates was interviewed separately by the panel.

either and neither(used for 2)

but all these use the verb as singluar

example:
none of the pens is working.
either of the two students will complete the work.
